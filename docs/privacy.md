# Privacy Policy — Coordinate Codex Tasks

Effective date: September 30, 2026

This policy describes the community skill and skills-only plugin published by
EasyVibeCoding at https://github.com/easyvibecoding/coordinate-codex-tasks.

## What the package does

The package contains workflow instructions and reference documents. It does not
operate an EasyVibeCoding server, provide an MCP endpoint, install lifecycle hooks,
or include analytics, advertising, or telemetry. Installing the package does not
send your conversations, files, or Task results to EasyVibeCoding.

## Information used during a workflow

When you request Task coordination, the model may use your assignment, relevant
Task identifiers and status, progress messages, selected artifacts or results,
and the coordinator/worker/monitor mapping to carry out that request. The workflow
can create a Task containing the assignment, read progress, send an authorized
follow-up to that Task, and save a heartbeat prompt containing the checkpoint and
next check. Include only the information needed for the assignment.

Those operations use tools supplied by your Codex or ChatGPT environment. Task
messages and automation prompts are processed and stored by that environment,
and may be available to people who already have access to the relevant workspace
or project. A skills-only installation does not add access to other accounts or
override the host's permissions. If you separately authorize work with another
service, that service's own data handling applies to that operation.

EasyVibeCoding does not receive, collect, retain, sell, or disclose that runtime
data through this package. OpenAI's processing and retention are governed by
your applicable account or workspace settings and OpenAI's policies, including
https://openai.com/policies/privacy-policy/. This package does not define a
separate retention period for host-managed chats, Tasks, files, or automations.

## Support information

If you voluntarily open a public GitHub issue, EasyVibeCoding can see the GitHub
username, issue text, and attachments you submit and uses them to investigate and
respond to the report. Public issue content is also visible to other GitHub
visitors. Do not include credentials, private conversations, personal documents,
or sensitive information in a public issue; a minimal redacted example is usually
sufficient.

We do not copy support submissions to a separate support database. Issue content
remains in the repository until it is deleted or redacted through GitHub's
available controls; closing an issue does not delete it. GitHub may retain copies
under its own policy:
https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement.

## Your controls

You can choose not to invoke the skill, disable or uninstall the plugin, ask the
coordinator to stop monitoring, and use the host's controls to pause or delete
automations and manage Tasks or chat history. Uninstalling the package does not
automatically remove Tasks or automations previously created in the host.

For a support-content correction or deletion request, contact the maintainers at
https://github.com/easyvibecoding/coordinate-codex-tasks/issues without reposting
the sensitive content. Deletion from the repository cannot remove copies already
made by third parties. Host-managed data requests should be directed to the host
provider using its privacy controls.

## Changes and contact

Updates to this policy will be published in this file with a revised effective
date. Support and privacy questions can be directed to the repository maintainers
through the GitHub issue page above.
